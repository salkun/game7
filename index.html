📚 Peta Ciri Khas 7 Tipe Data Standar dalam Python

Amati tanda baca khas masing-masing tipe data sebelum kelompokmu maju merakit kode di PID:

1. int (Integer)

Bilangan bulat (+/-) tanpa koma & tanpa kutip.

umur = 13

2. float (Desimal)

Angka desimal memakai tanda titik (.).

tinggi = 154.5

3. str (String)

Teks diapit tanda kutip ganda/tunggal.

nama = "Ali"

4. bool (Boolean)

Hanya 2 nilai: True atau False.

lulus = True

5. list (Daftar)

Pakai kurung siku [ ], isinya BISA diubah.

nilai = [85, 90]

6. tuple (Tetap)

Pakai kurung biasa ( ), TIDAK BISA diubah.

tgl = (13, 5, 2013)

7. dict (Dictionary / Kamus)

Pasangan kunci dan nilai (key-value) memakai kurung kurawal { "kunci": nilai }.

siswa = {"nama": "Ali", "nilai": 85}
